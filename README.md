# Gym Progress Tracker Android Application

The mobile application makes it easy to track one's progress in the gym.

## Features implemented:
* Entering weights and repetitions
* The ViewModel (business logic) is almost fully implemented.
* Adding exercises to current workout
* Quick start workout (start from empty workout)
* A pre-saved workout can be started (all exercises are loaded to current workout)


## Features to be implemented:

* Saving workout data to database
* Generating statistics based on past workouts
* Creating new pre-saved workouts
